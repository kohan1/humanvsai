Why the best model is not the last one

While it trains, the model stops every 250,000 steps and plays fifteen games. The games never change — same starting pieces, same order — so every check is measuring the model, not luck of the draw.

Left to right is training progress. Each dot is one of those checks. They swing by hundreds of points on identical games — so the model you happen to stop on is close to a coin flip. The solid line is the best score seen so far, and training saves a copy every time that line steps up. Without it, whatever the run ended on would be what shipped, and three earlier runs ended below the model they started from.

How good it got, for how much training

Every finished run, scored over 30 to 60 full games after it ended. This is the headline question — does more training actually buy more skill?

Sideways is total training, not the length of one run: a run that continues from an earlier model inherits everything that model already learned, so 4M steps on top of a 10M-step model sits at 14M. Up is the score it achieved. The line only joins versions that were kept — a run that scored worse was discarded, so nothing was ever built on top of it, and joining it to the line would suggest otherwise. The family tree

Training did not run in a line. Every run starts from some earlier model, and when one came out worse it was abandoned and the next attempt went back to the last good version instead.

Each dot is one training run, placed left to right by how much total training it represents, with its evaluated score printed above it. A curve joins a run to the model it started from. The straight row across the middle is the surviving line — the ancestry of what the site serves today. Everything hanging below it is a branch that stopped: a run that finished below the model already shipped, so it was kept as a record and never built on. Two of Watermelon's branches leave from the same parent, which is what trying twice from a known-good model looks like.

The same model, sixty games

Nothing changes between these games — same model, same weights, same starting conditions. Every difference in the result comes from how the game itself unfolded.

Sideways is the score; each bar counts how many of the sixty games finished in that band. Snake's ran from 41 to 177 — the best game was four times the worst, from an identical opponent. Note how far apart the mean and median sit: a handful of games that ended almost immediately drag the average well below the typical result. That gap is why one evaluation proves very little, and why a model is only replaced when it wins over dozens of games rather than one.

What the network actually is

Read straight out of the model files the site ships, so it cannot drift from what is really running.

Read left to right: numbers describing the board go in one end, and a score for every move the AI could make comes out the other. Each box in between is a layer of the network, and its figures are the shape of that layer's weight matrix — outputs × inputs. So 1024 × 238 means 1,024 units each looking at all 238 input numbers, which is where its 243,712 weights come from. A convolution layer slides one small filter across the board, so it learns shapes wherever they appear; a dense layer connects everything to everything. Snake and Watermelon see a grid and use both; Tetris is dense throughout. Every one of those weights started as a random number and was moved only by playing.

The Tetris bot's actual brain

Not a diagram of a neural network — this one. Every line is a real weight read out of the model file the site ships, drawn at its true strength: blue pulls an option up, red pushes it down. Hover a neuron to isolate what it is connected to.

Each column is a layer, each dot one neuron, and each line a real connection between them. Numbers describing the board enter on the left and a score for every possible move leaves on the right. A neuron brightens as it fires, and a line is only lit while the neuron feeding it is active — so you are watching signal find a path, not a loop of decoration. Most neurons sit dark at any moment, which is genuinely how this kind of network behaves. Hover any neuron to mute everything except its own connections.
